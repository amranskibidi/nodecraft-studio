**NodeCraft Studio** is a modern, high-performance web-based visual node graph editor built specifically for game developers, technical designers, and system architects. It streamlines the workflow of designing game feature logic, mapping system architectures, modeling data pipelines, and generating structured AI context prompts for LLMs (such as Gemini, ChatGPT, or Claude).

---

## ✨ Features

- 🧠 **Interactive Visual Node Canvas**: Seamlessly create, edit, drag, pan, and zoom across an infinite grid space.
- ⚡ **Glowing Bezier Wires**: Dynamic bezier connection cables featuring custom neon color palettes (*Neon Cyan, Emerald, Electric Violet, Amber Gold, Neon Rose*).
- 🤖 **AI Prompt Exporter**: Automatically serializes your node graph structure into clean, structured Markdown prompts optimized for LLM code generation.
- 📤 **Multi-Format Export**: Export your entire canvas as high-definition **PNG** images, **PDF** documents, or save/load native **JSON** project state files.
- 🛡️ **Safe Workspace Controls**: Built-in canvas clear confirmation modal with intuitive visual alerts to prevent accidental loss of work.
- 🎨 **Futuristic Dark Interface**: Built with Tailwind CSS v4, sleek backdrop blur aesthetics, and vector icons by Lucide React.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Export Engines**: [html2canvas](https://html2canvas.hertzen.com/) & [jsPDF](https://github.com/parallax/jsPDF)
